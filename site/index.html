Fonts everywhere.
Found nowhere.

A zip from a client, a folder from an old laptop, that typeface you bought for one invite. Desktop font managers only see one machine. Typestash turns a folder on your server into a font library you can open from anywhere.

What it does

A font manager that lives on your server.

Everything is read from inside the font files: names, weights, axes, features, scripts and licences. Not guessed from file names.

01

Every font, at a glance

Each card is set in its own font. Type your own sample, resize, and switch between grid and list.

  • Filter by sans, serif, mono, display or script, variable fonts and italics
  • A Scripts menu built from your library: Cyrillic, Greek, Arabic, Devanagari and more
  • Saved preview presets, favourites and collections
02

Dig into every family

A proper type tester for every family, with the details you normally need three apps for.

  • Variable-axis sliders with an animate button, plus named instances
  • OpenType feature toggles: ligatures, small caps, figures, stylistic sets
  • Waterfall, pairing suggestions and a full glyph map (click to inspect, double-click to copy)
03

Compare side by side

Put up to eight fonts head to head and actually choose.

  • Columns, rows, or an overlay on one shared baseline
  • Metric bars for x-height, cap height, width and more, lined up across fonts
  • One weight slider drives every font, variable or static
04

Twelve themes, keyboard first

Paper, Ink, Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox and more. Every theme passes WCAG AA for text.

  • A command bar for everything: ⌘K on macOS, Super+K on Linux, Ctrl+K on Windows
  • / search, [ sidebar, d light or dark, , settings
  • Works on phones and tablets too
And the rest

Drag, drop, done

Drop fonts or .zip archives anywhere on the page. They're validated, de-duplicated and filed as Uploads/<Family>/.

Download anything

One style, a whole family as a zip, a collection, or a PNG specimen sheet.

Real metadata

Designer, foundry, version, licence and language support, read from inside each font.

Housekeeping

A duplicates and issues page lists identical files and fonts that can't be read. Nothing is ever deleted.

Every format

TTF, OTF, WOFF, WOFF2 and TTC/OTC collections, including every face inside a collection.

Yours, privately

Runs on your hardware. No accounts, no telemetry, and an optional password for the whole app.

Self-host it

Your server. Your fonts. One command.

A small multi-arch image for x86 and ARM: NAS boxes, Raspberry Pi, Apple Silicon. Your fonts folder stays as it is.

~/typestash
$ docker run -d --name typestash -p 8080:8080 \
    -v "$PWD/fonts:/fonts" -v "$PWD/data:/data" \
    -e PUID=$(id -u) -e PGID=$(id -g) \
    --restart unless-stopped \
    ghcr.io/jatinkrmalik/typestash:latest
# then open http://localhost:8080 and drop some fonts on the page

Questions

Frequently asked.

What is Typestash?

A self-hosted font library and font manager. Point it at a folder of fonts on your server or NAS and you get a searchable web gallery with live previews, a type tester, glyph maps, side-by-side compare, collections and downloads, from any browser on any device.

Is it a FontBase or NexusFont alternative?

For browsing, previewing, comparing and organising, yes, with one difference: desktop font managers live on one computer, while Typestash runs on your server and works in any browser. It doesn't install fonts into your operating system yet; syncing a collection to your desktop is on the roadmap.

How do I install it?

One Docker command (see Self-host it above). There's also a Docker Compose file and an Unraid template in the repo, or you can run it without Docker on Python 3.11+. Then open port 8080 and drop some fonts on the page.

Which font formats does it support?

TTF, OTF, WOFF and WOFF2, plus TTC/OTC collections, where every face inside is listed on its own. You can also upload .zip archives of fonts.

Will it change or delete my font files?

No. Typestash only reads your fonts folder. New uploads are added under Uploads/<Family>/, duplicates are skipped, and nothing is ever modified or deleted.

Can I use my fonts as web fonts on my own sites?

Not yet. That's the next big feature: a self-hosted font registry that serves the families you choose as web fonts, Google Fonts style, with licence checks, since not every font is allowed on the web.

Does it need the internet, or track me?

No. It runs entirely on your own hardware and works offline on your local network. There are no accounts, no telemetry and no calls home.

Can I put it behind a password?

Yes. Set TYPESTASH_PASSWORD for built-in basic auth, or put it behind your reverse proxy's login (Authelia, Authentik and the like) or a VPN such as Tailscale.

Does it run on a Raspberry Pi or an ARM NAS?

Yes. The image is built for both amd64 and arm64, so it runs on Raspberry Pi 4 and 5, Apple Silicon and most ARM-based NAS boxes.

Is it free?

Yes. Typestash is free and open source under the MIT licence. If it's useful to you, you can sponsor it.
