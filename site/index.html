Fonts everywhere.
Found nowhere.

A zip from a client, a folder from an old laptop, that typeface you bought for one invite. Desktop font managers only see one machine. Typestash turns a folder on your server into a font library you can open from anywhere.

What you get

Built for people who collect type.

Everything is read from inside the font files: names, weights, axes, features, scripts and licences. Not guessed from file names.

01 · GALLERY

Every font, at a glance

Each card is set in its own font. Type your own sample, resize, and switch between grid and list.

  • Filter by sans, serif, mono, display or script, variable fonts and italics
  • A Scripts menu built from your library: Cyrillic, Greek, Arabic, Devanagari and more
  • Saved preview presets, favourites and collections
02 · FAMILY

Dig into every family

A proper type tester for every family, with the details you normally need three apps for.

  • Variable-axis sliders with an animate button, plus named instances
  • OpenType feature toggles: ligatures, small caps, figures, stylistic sets
  • Waterfall, pairing suggestions and a full glyph map (click to inspect, double-click to copy)
03 · COMPARE

Compare side by side

Put up to eight fonts head to head and actually choose.

  • Columns, rows, or an overlay on one shared baseline
  • Metric bars for x-height, cap height, width and more, lined up across fonts
  • One weight slider drives every font, variable or static
04 · THEMES & KEYBOARD

Twelve themes, keyboard first

Paper, Ink, Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox and more. Every theme passes WCAG AA for text.

  • A command bar for everything: ⌘K on macOS, Super+K on Linux, Ctrl+K on Windows
  • / search, [ sidebar, d light or dark, , settings
  • Works on phones and tablets too
⤓

Drag, drop, done

Drop fonts or .zip archives anywhere on the page. They're validated, de-duplicated and filed as Uploads/<Family>/.

◫

Download anything

One style, a whole family as a zip, a collection, or a PNG specimen sheet.

⌗

Real metadata

Designer, foundry, version, licence and language support, read from inside each font.

♲

Housekeeping

A duplicates & issues page lists identical files and fonts that can't be read. Nothing is ever deleted.

Aa

Every format

TTF, OTF, WOFF, WOFF2 and TTC/OTC collections, including every face inside a collection.

⚿

Yours, privately

Runs on your hardware. No accounts, no telemetry, optional password for the whole app.

Self-host it

Your server. Your fonts. One command.

A small multi-arch image for x86 and ARM: NAS boxes, Raspberry Pi, Apple Silicon. Your fonts folder stays as it is.

~/typestash
$ docker run -d --name typestash -p 8080:8080 \
    -v "$PWD/fonts:/fonts" -v "$PWD/data:/data" \
    -e PUID=$(id -u) -e PGID=$(id -g) \
    --restart unless-stopped \
    ghcr.io/jatinkrmalik/typestash:latest
# then open http://localhost:8080 and drop some fonts on the page
